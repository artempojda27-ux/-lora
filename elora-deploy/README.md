# ÉLORA — витрина

Статический сайт на реальном каталоге TAPULI. Без сборки и зависимостей.

## Структура

```
index.html          разметка, стили и логика (56 КБ)
data/catalog.js     каталог: 471 карточка, 14 категорий (324 КБ)
assets/hero.jpg     фото первого экрана
assets/mono.png     монограмма ÉL
assets/og.jpg       превью для соцсетей 1200×630
assets/icon-*.png   фавикон и иконка iOS
vercel.json         кеш и заголовки безопасности
```

## Деплой на Vercel

```bash
npm i -g vercel
cd deploy
vercel          # предпросмотр
vercel --prod   # боевой домен
```

Либо через веб: перетащить папку на vercel.com/new. Сборка не нужна — Framework Preset: **Other**, Build Command оставить пустым.

## После первой заливки — проверить

1. **Загружаются ли фото товаров.** Они лежат на `img.tapuli.shop`. Если карточки пустые — поставщик режет хотлинк, и картинки надо складывать к себе при импорте.
2. Открыть с телефона: меню, лист фильтров, корзину.
3. Прогнать Lighthouse.

## Перед боевым запуском

- Заменить `elora.ua` на реальный домен в `index.html` (canonical, og:image), `robots.txt`, `sitemap.xml`
- Подставить настоящий телефон вместо `+38 097 073 55 33`
- Заполнить страницы: доставка и оплата, обмен и возврат, таблица размеров
- Подключить аналитику

## Обновление каталога

Сейчас `catalog.js` статичен — это снимок фида. Чтобы каталог жил сам:

1. Скачивать XML: `https://tapuli.shop/price-xml/?datefrom=…&dateto=…&xml-feed=1&platform=standard`
2. Прогонять через `normalize.py` → JSON
3. Пересобирать `catalog.js` и деплоить

Дальше это переносится в cron на сервере или в Vercel Cron с записью в базу.

**Важно:** фид отдаёт только то, что есть в наличии, поля с количеством в нём нет. Импорт должен быть полным перезаливом, иначе исчезнувшие позиции останутся висеть в каталоге.

## Что не работает без бэкенда

- Каталог не обновляется сам
- Корзина живёт до перезагрузки страницы
- Заказ никуда не отправляется — форма показывает экран подтверждения
- Нет оплаты и интеграции с Новой почтой
