# ÉLORA — витрина

Статический сайт на реальном каталоге TAPULI (взуття) + відділ «Сумки та аксесуари» з 4cases.com.ua. Без сборки и зависимостей.

Дизайн: светлая палитра в духе Hermès (тёплая бумага, оранжевый акцент, Cormorant Garamond) и интерфейс в духе Apple (стеклянная шапка, скругления, сегмент-контролы, Inter).

## Структура

```
index.html          разметка, стили и логика (56 КБ)
data/catalog.js     обувь TAPULI: 491 модель, 17 категорий (генерирует import_tapuli.py)
img/tp, img/4c      фото карточек на своём хостинге (WebP)
import_tapuli.py    импорт фида TAPULI
data/4cases.js      4cases: 449 карточек, 9 категорий — сумки, гаманці, портмоне, ремені (генерирует import_4cases.py)
import_4cases.py    импорт каталога 4cases.com.ua
admin.html          админка цен (не индексируется)
data/prices.js      ручные цены из админки поверх фидов
ambient.js          анимированный фон «шёлк и кожа»
assets/hero.jpg     фото первого экрана
assets/mono.png     монограмма ÉL
assets/og.jpg       превью для соцсетей 1200×630
assets/icon-*.png   фавикон и иконка iOS
vercel.json         кеш и заголовки безопасности
```

## Деплой на Vercel

```bash
npm i -g vercel
cd deploy
vercel          # предпросмотр
vercel --prod   # боевой домен
```

Либо через веб: перетащить папку на vercel.com/new. Сборка не нужна — Framework Preset: **Other**, Build Command оставить пустым.

## После первой заливки — проверить

1. **Загружаются ли фото товаров.** Они лежат на `img.tapuli.shop`. Если карточки пустые — поставщик режет хотлинк, и картинки надо складывать к себе при импорте.
2. Открыть с телефона: меню, лист фильтров, корзину.
3. Прогнать Lighthouse.

## Перед боевым запуском

- Заменить `elora.ua` на реальный домен в `index.html` (canonical, og:image), `robots.txt`, `sitemap.xml`
- Подставить настоящий телефон вместо `+38 097 073 55 33`
- Заполнить страницы: доставка и оплата, обмен и возврат, таблица размеров
- Подключить аналитику

## Обновление каталога

Сейчас `catalog.js` статичен — это снимок фида. Чтобы каталог жил сам:

```bash
python3 import_tapuli.py    # скачать свежий фид, пересобрать catalog.js, докачать фото
```
Скрипт сам качает фид, прогоняет его через `normalize.py`, пишет `data/catalog.js`
и сохраняет первые два фото каждой модели в `img/tp` (остальная галерея — через
оптимизатор Vercel). Фото поставщика со временем удаляются, поэтому каталог стоит
обновлять регулярно — старый снимок быстро теряет картинки.

Дальше это переносится в cron на сервере или в Vercel Cron с записью в базу.

**Важно:** фид отдаёт только то, что есть в наличии, поля с количеством в нём нет. Импорт должен быть полным перезаливом, иначе исчезнувшие позиции останутся висеть в каталоге.

## Что не работает без бэкенда

- Каталог не обновляется сам
- Корзина живёт до перезагрузки страницы
- Заказ никуда не отправляется — форма показывает экран подтверждения
- Нет оплаты и интеграции с Новой почтой

## Каталог 4cases (сумки та аксесуари)

```bash
python3 import_4cases.py --markup 1.6   # опт -> роздріб; без флага цены как на сайте
```

Скрипт обходит категории `4cases.com.ua/catalog/<slug>?page=all` и пишет `data/4cases.js`
(`DATA_4C`, `CATS_4C`). Сайт подхватывает файл сам: появляется плитка отдела, категории
в меню и фильтрах, товары без размера («one size»). Пока файла нет — плитка «Незабаром».
Берутся только позиции в наличии; разделы «бувші в продажу» и «некондиція» пропускаются.
Импорт — полный перезалив файла. Цены в снимке — как на сайте 4cases (оптовые), для
розницы перезапустить с `--markup`. Фото грузятся напрямую с `4cases.com.ua`.

## Админка цен — `/admin`

Отдельная страница `admin.html` (на Vercel открывается как `/admin`):

- массово: изменить на %, умножить (наценка), прибавить ₴, задать цену, скидка % с зачёркнутой
  старой ценой, убрать скидку, округлить (до 10/50/100 ₴, на …9 или …99), вернуть цены из фида;
  применяется ко всем товарам по фильтру (отдел, категория, поиск) или к отмеченным галочками;
- вручную: цена и старая цена прямо в таблице, Enter — к следующей строке, «Скасувати» / Ctrl+Z;
- «Зберегти на сайт» коммитит `data/prices.js` в GitHub через API, Vercel сам передеплоит сайт.
  Нужен fine-grained токен только на этот репозиторий с правом **Contents: Read and write**
  (вводится в настройках ⚙ и хранится только в браузере). Ветка по умолчанию — `main`.
- «Файл» — скачать `prices.js` вручную, если GitHub не настроен.

Ручные цены хранятся отдельно от фидов, поэтому повторный импорт `catalog.js` / `4cases.js`
их не затирает. Страница без пароля: без токена она ничего не может изменить на сайте.
