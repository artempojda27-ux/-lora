Публікація

Ціни зберігаються у файл data/prices.js у вашому репозиторії GitHub, після чого Vercel сам оновлює сайт (1–2 хв). Токен зберігається лише в цьому браузері.

Створіть на github.com → Fine-grained token: лише цей репозиторій, дозволи Contents: Read and write та Actions: Read and write (для кнопки «Оновити каталог»).

Замовлення в Telegram

Перевіряємо…

  1. У Telegram відкрийте @BotFather → /newbot → скопіюйте токен.
  2. Vercel → проєкт lora → Settings → Environment Variables: TELEGRAM_BOT_TOKEN = токен → Save → Deployments → Redeploy.
  3. Напишіть своєму боту /start (або додайте його в робочу групу й напишіть там).
  4. Натисніть «Знайти чати», оберіть свій і збережіть — замовлення почнуть приходити.
